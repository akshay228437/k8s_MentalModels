# Kubernetes Setup on EC2

Create **3 fresh Ubuntu 24.04 x86_64 EC2 instances** (`t3.medium` or larger): **1 master + 2 workers**, in the same VPC with internet access.

Security group: allow **all traffic from the same cluster security group**, and **SSH (22) from your IP**. Your VPC must not overlap `192.168.0.0/16` or `10.96.0.0/12`.

Both scripts install fixed **Kubernetes 1.34.5**. The master script also initializes the cluster, configures kubectl, and installs **Calico 3.31.0** networking.

## 1. Run on the master EC2

```bash
sudo apt-get update
sudo apt-get install -y curl ca-certificates
curl -fL https://raw.githubusercontent.com/akshay228437/k8s_MentalModels/main/InstallationMasterNode/master.sh -o master.sh
sudo bash master.sh
```

Wait for **Master setup complete**.

## 2. Run on each worker EC2

```bash
sudo apt-get update
sudo apt-get install -y curl ca-certificates
curl -fL https://raw.githubusercontent.com/akshay228437/k8s_MentalModels/main/InstallationMasterNode/worker.sh -o worker.sh
sudo bash worker.sh
```

Repeat on both workers.

## 3. Join the workers

Generate the join command on the **master**:

```bash
sudo kubeadm token create --print-join-command
```

Copy the complete output and run it with **sudo on each worker**. It will look like:

```bash
sudo kubeadm join MASTER_PRIVATE_IP:6443 --token TOKEN --discovery-token-ca-cert-hash sha256:HASH
```

Use the actual command generated by your master. If the token expires, generate a new one with the same command.

Then check on the **master**:

```bash
kubectl get nodes -o wide
```

Wait until all **3 nodes** show **Ready**.
